How Steganography Works

What is steganography?

Steganography hides data inside a normal-looking image by tweaking the least significant bits of each pixel's color. The changes are too small to see, so the picture looks the same, but you can extract the hidden data later.

Why PNG?

The encoded image must be saved as PNG. JPEG and similar formats compress the image in ways that destroy the hidden bits. PNG keeps every pixel exactly as it is.

How much can you hide?

It depends on the carrier image size. Bigger images hold more data. A 1920 × 1080 photo has over 2 million pixels, which is enough for several hundred kilobytes of text.

How text encoding works

Each pixel stores 3 bits of data (one per color channel). The first 32 bits store the message length, and the rest carry the actual text as UTF-8.

Capacity

Max text = (pixels × 3 − 32) ÷ 8 bytes. For example, a 100 × 100 image can hold about 3 747 bytes.

How decoding works

The decoder reads the first 32 bits to find out how long the message is, then extracts the text from the pixel bits.

How image encoding works

The secret image's dimensions are stored in the first 64 pixels of the carrier. Then each pixel of the secret image takes 8 carrier pixels to store its color values. Only RGB values are embedded; the alpha channel is not stored.

Capacity

Max secret pixels = (carrier pixels − 64) ÷ 8. A 1920 × 1080 carrier can hold a secret image up to about 259 136 pixels (roughly 509 × 509).

Scaling

If the secret image is too big, Scale down to fit shrinks it until it fits. The recovered image will be smaller than the original.

Overwriting secrets

Encoding into an image that already has hidden data will overwrite it. The old secret is gone. Also, if you scale down a secret image that itself contains hidden data, that data will be lost too. Always use a clean image as your carrier.

Limitations

The alpha channel (transparency) of the secret image is not preserved. The extracted image will always be fully opaque. Support for transparency may be added in a future version.
